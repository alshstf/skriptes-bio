# skriptes-bio — датасет био-таймлайнов авторов

Курируемый датасет для [skriptes](https://github.com/alshstf/skriptes): вехи жизни писателей рядом с их книгами
(«В жизни автора в это время» на карточке книги, страница «Жизнь и книги» автора).

- `authors/<QID>.json` — автор по Wikidata QID: даты жизни, главы жизни, вехи (`short` ≤ 60 символов без года и
  названий своих работ, `long`, тип, уровень major/minor, связи с работами), работы с периодами написания, у каждой вехи
  `evidence` — цитата-основание из источника.
- `context/<регион>.json` — исторический фон (тонкие строки на полном таймлайне).

Схема и правила — в коде skriptes: `backend/internal/bio/schema.go`, `validate.go`.

## Откуда данные

Генератор `biogen` (skriptes, `backend/cmd/biogen`): Wikidata-скелет + статьи Википедии (ru, en при короткой ru, язык
оригинала автора) → извлечение моделью Claude по строгой схеме → автопроверка (цитата находится в статье, год — в
цитате или в фактах Wikidata, сверка браков/детей/утрат с Wikidata, правила датасета) → ревью. Золотой набор (8 авторов)
собран вручную. Даты — ISO нового стиля.

## Как используется

skriptes закрепляет коммит этого репозитория в `backend/internal/bio/dataset.ref`; сборка образа скачивает его,
`biogen pack` проверяет и упаковывает в сжатый пакет без `evidence`, приложение сеет пакет в Postgres при смене версии.
Новые авторы — PR сюда, затем бамп `dataset.ref` в skriptes.

Проверка локально (рядом чекауты обоих репо):

```bash
cd skriptes/backend
go run ./cmd/biogen check -dir ../../skriptes-bio
```

## Лицензия

Формулировки вех — собственные, на основе статей Википедии; цитаты `evidence` — дословно из Википедии. Датасет
распространяется по [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/) с атрибуцией: «По материалам
Википедии (CC BY-SA 4.0) и Wikidata (CC0)»; ссылки на статьи-источники — в поле `sources` каждого автора.
